# Dictionary / Word Search System

## About the Project
The Dictionary / Word Search System is a Data Structures project developed to store, search, and manage words efficiently.

It provides a simple interface where users can add new words, search existing words, delete words, and display all stored words.

## Objectives
- To store words efficiently.
- To search words quickly.
- To add new words to the dictionary.
- To delete existing words.
- To display all stored words.

## Technologies Used
- C Programming Language
- Data Structures
- File Handling (Optional)

## Features
- Add a new word
- Search a word
- Delete a word
- Display all words
- Update existing words
- User-friendly menu-driven interface

**Note:** This project is developed for educational purpose to demonstrate the implementation of Data Structures.

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Compile the source code using any C compiler (GCC, Code::Blocks, Turbo C, or VS Code).
4. Run the executable.
5. Use the menu to manage dictionary words.
